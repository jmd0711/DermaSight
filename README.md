# DermaSight
DermaSight is an application that helps users quickly assess the potential risks of their skin lesions. By analyzing images and narrowing down possible conditions, the tool aims to educate users, reduce uncertainty, and offer guidance on next steps.

## Deployment
Frontend: https://derma-sight-o3j89v96v-jasper-matthew-dumdumayas-projects.vercel.app/

Backend: https://dermasight-1tmz.onrender.com/

## Setup
### Frontend
To run the development server:
```bash
cd dermasight_
```
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
### Backend
```bash
cd dermasight-backend
```
```bash
pip install -r requirements.txt
```
```bash
python store_index.py
```
